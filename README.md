# Sorts

Various sorting algorithms written in C++.

## Building

Use [CMake](cmake.org) to build the various sample programs in the project like so:
```
cmake -S . -B build
cmake --build build/
```

Alternatively, this can be condensed to a single shell script invocation like so:
```
./build_all.sh build
```
